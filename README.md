Merupakan projek dari Computer Vision atau pemrosesan data berdasarkan image yaitu aplikasi deteksi penyakit tanaman jagung 
aplikasi ini mengklasifikasikan 4 jenis data klasifikasi yaitu Corn Common Rust, Corn Northern Leaf Blight, Corn Gray Leaf Spot, dan yang teakhir kategori Corn Healty/Kondisi Sehat.
aplikasi ini menggunakan metode Convolutional Neural Network dan dengan arsitektur Inception V3 mendapat skor akurasi 97%
untuk memudahkan di gunakan oleh user maka kami melakukan deployment dengan menggunakan streamlit.
